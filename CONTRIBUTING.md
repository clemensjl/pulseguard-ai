# Contributing

PulseGuard AI is a demo of an uptime and status page product. Bug reports and small, focused pull requests are welcome.

## Setup

1. Fork and clone the repository.
2. `npm install`
3. `npm run dev` starts the app on http://localhost:3000.

No environment variables are needed. Monitors, incidents and plans in the dashboard are seeded sample data kept in the browser.

## Check

```bash
npm run build
```

The build includes the TypeScript check. CI runs the same command.

## Pull request

1. Branch from `master`, one change per pull request.
2. Describe what changes and why. Attach a screenshot for visible changes.
3. Open the pull request against `master`.
